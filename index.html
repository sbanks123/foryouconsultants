Data & Architecture
Where numbers come from and how to automate them
How to get real TikTok numbers into this app
A profile link alone cannot produce analytics. TikTok blocks automated page reads, and a browser page cannot call TikTok from your visitor's machine because of cross-origin restrictions. Follower counts and view counts on a public profile also do not include reach, engagement rate, click-throughs, or audience demographics — those live only inside the account owner's analytics.
Option 1 — Analytics export (works today, no build)
In the TikTok mobile app: Profile → menu → Creator tools → Analytics → Overview. On desktop at tiktok.com, Analytics has a Download data button that produces a CSV. Drop that CSV into Add Data and every chart fills with genuine numbers.

Option 2 — Manual weekly entry (works today)
Add Week lets you type the figures straight off the analytics screen. Engagement rate is computed for you from likes, comments, shares, saves and reach.

Option 3 — TikTok API (needs a backend)
Register at developers.tiktok.com, request the Display API and Research or Business scopes, and run the OAuth exchange server-side so the client secret never reaches the browser. A Lambda behind API Gateway stores the refresh token in Secrets Manager and writes results into the metrics table on a schedule. Instagram, Facebook and LinkedIn follow the same pattern through the Meta Graph API and LinkedIn Marketing API. X requires a paid API tier.

Model port path
The network in AI Insights runs in TensorFlow.js. The layer stack (Dense/ReLU → Dense/Tanh → Dense/Softsign → Sigmoid regression head, plus a ReLU → Tanh → Softmax classifier head) maps one-to-one onto Keras. Export with model.save(), load in SageMaker with tf.keras.models.load_model(), retrain on the full history in S3, and serve from a SageMaker endpoint called by Lambda.
